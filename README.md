# IT Service Desk Analytics Dashboard

## Project Overview
An Excel-based analytics project designed to monitor IT support tickets, evaluate resolution performance, and identify opportunities to improve service efficiency.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization
- KPI Analysis

## Key Performance Indicators
- Total Tickets: 280
- Resolved Tickets: 234
- Resolution Rate: 83.6%
- Average Resolution Time: 42.76 hours

## Dashboard Features
- Ticket status distribution
- Ticket categories and priorities
- Ticket volume trends
- Average resolution time analysis

## Project Objective
To transform IT service desk data into actionable insights that support operational monitoring and decision-making.
